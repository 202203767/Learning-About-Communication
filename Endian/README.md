リトルエンディアン・ビッグエンディアンについて

エンディアンとは
複数バイトのデータをメモリに格納する順番のルール

リトルエンディアンとは
下位バイト（小さい桁）から格納する方式
0x12345678(16進数表記)の場合
+0 : 78
+1 : 56
+2 : 34
+3 : 12
Intel系CPUで採用

ビッグエンディアンとは
上位バイト（大きい桁）から格納する方式
0x12345678(16進数表記)の場合
+0 : 12
+1 : 34
+2 : 56
+3 : 78
TCP/IPの通信で採用されている

TCP/IPではビッグエンディアンに変換してから送信

通信でよく使う関数
ビッグエンディアンに変換
htons()16bit変換
htonl()32bit変換

リトルエンディアンに変換
ntohs()16bitを元に戻す
ntohl()32bitを元に戻す
