概要

ビット演算についてのプログラムを実装した。
AND (&)
OR (|)
XOR (^)
NOT (~)
左シフト
右シフト

ここで使う型
uint8_t・uint16_t・uint32_t・uint64_tは〇ビット符号なし整数のこと
数字はbit数（8だったら8bit(1バイト)）
0x〇〇は16進数表記
0〇〇は8進数
0b〇〇〇〇は2進数
下記が表

10進数  8進数  16進数  2進数
0       0      0x0     0b0000
1       1      0x1     0b0001
8       10     0x8     0b1000
10      12     0xA     0b1010
15      17     0xF     0b1111
16      20     0x10    0b10000
255     377    0xFF    0b11111111

printf("%d\n", data); // 10進数
printf("%o\n", data); // 8進数
printf("%X\n", data); // 16進数
