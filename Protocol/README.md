概要

LINについて

LINは車載分野においての低コストネットワークの実現が目的で作成された。
通信速度は1kbps～20kbps
ドアスイッチ、ミラーやダッシュボードスイッチなどがターゲットで、
CANのサブネットワークとしての利用がメイン。

固定値のLIN一覧

Sync Byte Field
0x55でほぼ固定値
Protected Identifier Field
0 ~ 59 (0x3B)　信号用
60 (0x3C)/ 61 (0x3D)　診断とコンフィグ用
62 (0x3E)/63 (0x3F)	予約(拡張用)

CANについて

CAN：ECU同士がリアルタイムでデータをやり取りするためのもの 
ドイツの電装メーカーであるBOSCH社が電子制御システム向けの通信プロトコルとして発案 
CANの特徴はデータの信頼性、確実性にある。 
現在では高速CAN・低速CANが存在し、それぞれISO11898-2・ISO11898-3として標準規格化され
ている。
